# 小蝶桌宠（Electron 客户端）

把平台助理「小蝶」放到桌面上：透明置顶的小人 + 对话气泡，点她就能说话。

这是需求文档 v1.2 里 **P1 / P2 的最小可用版**（静态形象 + 文字气泡 + 接后端对话 + Edge TTS 语音播报）。
**不含** Live2D 动作、截屏感知、主动搭话状态机 —— 那些属后续批次。

---

## 一、跑起来

### 0. 前置条件（必须）

桌宠只是个前端壳，它自己不产生回答。所以必须先有后端：

```bash
# 项目根目录
docker compose up -d postgres redis        # 数据库 + Redis（Docker Desktop 要先启动）
cd backend && npx prisma migrate deploy && npx prisma generate
npm run start:dev                          # 后端跑在 http://localhost:3000
```

桌宠需要登录，所以后端要能正常登录（数据库里有你的账号）。账号与网页版共用同一个。

> **端口被占用怎么办**：如果 `3000` 已经被别的程序占了（很常见），换端口启动后端：
> ```bash
> PORT=3100 npm run start:dev
> ```
> 然后在桌宠的登录面板里把**服务地址**填成 `http://localhost:3100`。
> 地址填错时的典型症状是「登录一直失败」或报「登录已过期」——因为连到的是另一个服务。

### 1. 启动桌宠

**推荐：从网页版点开** —— 登录网页版后，右上角有个小圆脸图标（悬停显示「打开桌宠」），点一下就行。
后端会帮你在本机把 Electron 拉起来；如果已经开着，就只是把她叫到最前面。

> 为什么这件事要后端代劳：浏览器沙箱**不允许网页启动本地程序**，
> 自定义协议（`xiaodie://`）又需要先安装注册、开发期常被拦。
> 所以走「网页 → `POST /api/desktop-pet/launch` → 后端 spawn」这条确定能通的路。
> 前提是后端和你在一台机器上；后端跑在服务器上时接口会明确报错，不会假装成功。

**或者命令行**：

```bash
cd desktop
npm install      # 第一次需要，会下载 Electron 二进制（约 100MB）
npm start
```

启动后：
- 屏幕**右下角**出现小蝶（透明背景，只看得见她本人）
- 系统托盘出现一个粉色小头像图标
- 从网页点开的话，**直接就是登录状态**（见下一节），气泡显示「我是小蝶，点我说点什么吧」

> 重复启动是安全的：主进程有 `requestSingleInstanceLock()`，
> 第二次启动会立刻退出、并让第一个实例把窗口显示出来，不会开出两个小蝶。

### 2. 登录：从网页点开时是自动的

**从网页点开** → 不需要登录。后端会把当前网页的登录态放进一个**一次性交接文件**，
桌宠启动时读走、立刻删除，然后自己在后台完成登录。你看到的就是「我是小蝶」。

**命令行 `npm start`** → 没有交接文件，第一次需要手动登录：
点一下小蝶 → 弹出设置面板 → 填服务地址 / 邮箱 / 密码 → 登录。
默认服务地址 `http://localhost:3000`，后端换端口就改这里。之后再启动会记住。

> **交接文件为什么不直接把 token 写进命令行参数**：
> 进程的命令行对同机任何用户都可见，那等于把 7 天有效的 JWT 写在公告板上。
> 所以后端只通过环境变量传**文件路径**，token 落在临时目录（0600 权限），
> 桌宠读完立即删除，后端还有 60 秒兜底清理。

## 二、怎么用

| 操作 | 效果 |
|---|---|
| **点一下**小蝶 | 弹出输入框，输入文字回车发送 |
| **拖拽**小蝶 | 移动位置（松手后自动记住，下次启动还在原地） |
| 点气泡右上角 `×` | 收起气泡 |
| 托盘**左键** | 显示 / 隐藏小蝶 |
| 托盘右键菜单 | 显示隐藏 / 重新连接 / 打开网页版 / 退出 |
| 托盘 →「退出」 | 真正结束进程（点窗口关闭只是隐藏） |

聊天时有流式反馈：她思考时头部摇摆加快、回答时嘴部动起来、文字一个字一个字出现。
她调工具时气泡会显示「正在查知识库…」这类提示，失败会明确告诉你哪一步没成。

### 语音播报（Edge TTS）

- **默认开启**。文字**跟着语音逐字出现**（边读边出字），不是先整段刷出来再等声音；嘴型跟着动。
- **开关有两个入口**（两边状态同步）：
  1. 窗口**右上角常驻的喇叭浮标**，点一下静音 / 恢复（静音时图标带斜杠、变灰）；
  2. 设置面板里的「语音播报」勾选框 + 「音色」下拉。
     设置面板的入口：右上角**齿轮按钮**、或**右键点小蝶**、或托盘菜单「设置…」。
     （登录后点小蝶只会弹输入框，不会再弹面板 —— 所以要靠这三个入口。）
- **音色**：四选一（甜美 / 温柔 / 东北 / 陕西）。默认跟随网页版人格里的音色。
- **同步是怎么做到的**：回复按句切开 → 逐句「合成 → 播放 → 播到哪句就把哪句写进气泡」，
  打字机的推进速度取自这段音频的**真实时长**（`AudioBuffer.duration`），所以字和声音基本同步。
  上一句在播时预取下一句（最多并行 2 条），尽量减少句间空白；太长的句子还会在逗号处再切一刀，
  让第一段音频更快回来、更快开口。
- **实现路径**（对应需求 §3.3「本地优先，失败回落后端代理」）：
  1. 本地用 `msedge-tts` 直接合成（无需密钥，连微软在线语音服务）；
  2. 本地失败 → 回落后端 `POST /api/tts/synthesize` 兜底；
  3. 两处都不通 → 只出气泡不出声，绝不影响对话。
- **为什么用 `msedge-tts` 而不是 `edge-tts`**：微软现在要求 `Sec-MS-GEC` **v2** 令牌（CS64 + SHA256 两段式），
  `edge-tts@1.0.x` 只发 v1 会直接 403；`msedge-tts` 已实现 v2 并带时钟偏差校正。

## 三、它和网页版是什么关系

- **同一个账号、同一个平台助理、同一份人格**：你在网页版「Agent 管理 → 平台助理 → 人格」里改的名字/语气，桌宠里立刻生效（气泡自称会跟着变）。
- **记忆是共享的**：桌宠的对话同样会沉淀进长期记忆，网页版的 3D 记忆网络里能看到。
- **会话是独立的**：桌宠第一次说话时会自动建一个叫「桌宠对话」的会话，不会和网页版的聊天记录混在一起。

## 四、几个设计上的取舍（为什么这么做）

### 1. 所有网络请求都在主进程

后端 `main.ts` **没有开 `enableCors()`**，而渲染进程是 `file://` 源（`Origin: null`），
直接 `fetch` 会被同源策略拦掉。所以：

- 主进程（Node 环境，不受 CORS 约束）负责登录、拉平台助理信息、发 SSE 对话
- 渲染进程只通过 IPC 拿事件，**拿不到 token**

顺带的好处是安全性：token 只存在于主进程，页面里任何脚本都偷不到。

### 2. token 加密后再落盘

存在 `%APPDATA%/XiaodiePet/pet-config.json`，token 用系统钥匙串
（Windows 上是 DPAPI，Electron 的 `safeStorage`）加密成密文，不是明文。

### 3. 鼠标穿透用「坐标命中」而不是 `e.target`

窗口开了 `setIgnoreMouseEvents(true, { forward: true })`，透明区域可以点穿到桌面。
但转发进来的 mousemove 事件**不做命中测试**，`e.target` 往往是 `<html>`，
用 `closest()` 永远判不到形象上。所以改成拿 `clientX/clientY` 去比
气泡 / 形象 / 输入框的 `getBoundingClientRect()`。

如果某些环境下还是点不中（不同 Windows 版本对 `forward` 支持有差异），
去设置面板把**「鼠标穿透」关掉**，窗口就恢复成普通可点窗口。

### 4. 形象是内联 SVG，不是图片

零素材依赖：不用带 PNG/Live2D 文件，改了配色直接改 SVG。
呼吸、眨眼、说话嘴型都是 CSS 动画，不需要 JS 逐帧算。
以后要换 Live2D，替换 `.pet-wrap` 里的内容即可，其余逻辑不用动。

### 5. 窗口尺寸固定 340×480

不做动态 resize（气泡变长就撑窗口会抖得很难受），气泡内部滚动，`flex-shrink` 保证
「气泡 + 输入条」同时出现时不会把形象挤出窗口。

### 6. SSE 的「说完了」靠空闲超时判定，不靠 EOF

主进程里读 `text/event-stream` 拿不到可靠的结束信号：后端明明已经 `response.end()`
（同一份请求用 Node 原生 `fetch` 测 3 秒就 close），但在 Electron 主进程里
`end` / `close` / `aborted` **一个都不触发**，会一直挂着不返回，
表现成「气泡一直在闪、输入框点不动」。

所以按空闲时间兜底，而且分两档：

| 阶段 | 阈值 | 原因 |
|---|---|---|
| 思考 / 调工具中 | 90 秒 | 模型可能几十秒不吐字，给足时间，别误判 |
| 已经出字之后 | 5 秒 | token 间隔通常 50~200ms，几秒没动静就是真结束了 |

提前结束的代价很小：只是说话动画早停，后续万一还有事件，气泡内容仍会照常更新。

## 五、已知限制

| 限制 | 说明 |
|---|---|
| 后端必须同机 | 「网页点开桌宠」依赖后端能在**本机** spawn Electron。后端部署到服务器后这个按钮会返回 503，只能用命令行 |
| 换账号要点一次 | 网页换账号后，再点一次「打开桌宠」就会把新登录态交接过去（桌宠会自动刷新并丢掉旧账号的会话） |
| 语音依赖网络 | Edge TTS 是微软在线服务；本地合成失败会回落后端代理，两处都不通时只出气泡不出声 |
| 没有 Live2D | 只有 SVG 表情（呼吸/眨眼/说话），没有可动骨骼模型 |
| 没有截屏感知 | 批次 C，且默认应该是关闭的 |
| 没有主动搭话 | 人格里的「主动搭话频率」目前只存配置，客户端还没读它来限频 |
| token 7 天后过期 | 后端 `JWT_EXPIRES_IN=7d`，且 `/auth/refresh` 还没实现。过期后点小蝶重新登录即可 |
| 没打包成 exe | 现在靠 `npm start` 跑。要分发给别人得加 `electron-builder` |
| 开机自启没做 | `DesktopPetSettings.autoLaunch` 字段有，接口还没实现 |

## 六、目录结构

```
desktop/
├── package.json
├── src/
│   ├── main.js              # 主进程：窗口 / 托盘 / 配置 / HTTP / SSE 解析
│   ├── preload.js           # contextBridge 白名单桥
│   ├── tts.js               # 本地 Edge TTS 合成（失败回落后端代理）
│   └── renderer/
│       ├── index.html       # 结构 + 内联 SVG 形象
│       ├── style.css        # 透明窗口样式 + 呼吸/眨眼/说话动画
│       └── pet.js           # 穿透判定 / 拖拽 / 气泡 / 面板
└── tray-icon.b64            # 托盘图标 base64（构建时已内联进 main.js，此文件仅留档）
```
