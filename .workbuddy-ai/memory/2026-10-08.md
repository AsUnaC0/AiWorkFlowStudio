# 2026-10-08 工作日志

## Skill + MCP 系统扩展

按照用户的设计建议，为 AI WorkFlow Studio 新增了 Skill 和 MCP 两个能力系统，覆盖前后端完整链路。

### 后端变更

**Prisma Schema** (`backend/prisma/schema.prisma`):
- 新增 `Skill` 模型 (id, workspaceId, name, description, type, instructions, inputSchema, outputFormat, workflowId, mcpServerId, mcpToolName)
- 新增 `McpServer` 模型 (id, workspaceId, name, description, transport, serverUrl, authType, credentials, status, lastError, availableTools)
- 更新 `Agent` 模型: 新增 `skillIds` 和 `mcpServerIds` String[] 字段（与现有 workflowIds/knowledgeBaseIds 模式一致）
- 更新 `Workspace` 模型: 新增 `skills` 和 `mcpServers` 关系
- 已执行 `prisma db push` + `prisma generate`

**Skill Module** (`backend/src/skill/`):
- `skill.module.ts` — imports PrismaModule
- `skill.controller.ts` — CRUD endpoints at `/api/workspaces/:workspaceId/skills`
- `skill.service.ts` — workspace member 权限校验
- DTOs: `create-skill.dto.ts`, `update-skill.dto.ts`

**MCP Module** (`backend/src/mcp/`):
- `mcp.module.ts` — imports PrismaModule
- `mcp.controller.ts` — CRUD + test connection at `/api/workspaces/:workspaceId/mcp-servers`
- `mcp.service.ts` — 含 MCP 协议通信 (initialize → notifications/initialized → tools/list)，支持 Streamable HTTP 传输，解析 JSON 和 SSE 两种响应格式
- credentials 字段不返回给前端（安全处理）
- DTOs: `create-mcp-server.dto.ts`, `update-mcp-server.dto.ts`

**AppModule**: 注册 `SkillModule` 和 `McpModule`

### 前端变更

**路由** (`fronted/src/router/index.ts`):
- 新增 `/skills` → SkillList
- 新增 `/mcp` → McpList

**侧边栏** (`fronted/src/layout/components/AppSidebar.vue`):
- BUILD 分组新增 Skills (icon: code) 和 MCP (icon: plugin) 菜单项
- activeMenu 高亮逻辑更新

**类型定义**:

- `fronted/src/types/mcp.ts` — McpServer, McpTool, CreateMcpServerRequest, UpdateMcpServerRequest, TestConnectionResult

**API 服务**:
- `fronted/src/api/skill.ts` — CRUD for Skills
- `fronted/src/api/mcp.ts` — CRUD + testMcpConnection for MCP Servers

**页面组件**:
- `fronted/src/views/skills/index.vue` — 双视图 (workspace 选择 → skill 列表)，含创建/编辑对话框 (name/description/type/instructions/input params/output format)，删除确认
- `fronted/src/views/mcp/index.vue` — 双视图 (workspace 选择 → MCP server 列表)，含创建/编辑对话框 (name/transport/serverUrl/authType/credentials)，测试连接，删除确认
