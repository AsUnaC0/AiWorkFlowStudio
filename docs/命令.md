启动数据库
在项目根目录：
docker compose up -d

检查：
docker compose ps

应该看到：
ai-workflow-postgres
ai-workflow-redis
都是运行状态。

连接 Prisma
测试：
pnpm prisma db pull

如果没有报错，说明：
NestJS
↓
Prisma
↓
PostgreSQL
已经打通。

查看数据库
pnpm prisma studio

执行 Migration
pnpm prisma migrate dev --name init

然后：
pnpm prisma generate

此时：
PostgreSQL
│
├── users
├── workspaces
└── workspace_members
建立起来。
