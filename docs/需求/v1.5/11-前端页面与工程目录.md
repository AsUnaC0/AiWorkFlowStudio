# 20. 前端页面与菜单建议

登录后默认进入 AI Chat。侧边栏核心导航建议为：

```text
Chat
Workspace
Knowledge Base
Agents
Skills
MCP Connections / MCP Servers
Settings
```

- `Chat`：消息区支持模型选择、Knowledge Base / Workflow / Agent 选择，并提供 Skill 与 MCP 工具选择入口。选择入口应区分“启用 Skill”和“允许调用 MCP 工具”，避免把两者展示成同一种资源。
- `Workspace`：管理 Workflow 等工作空间资源。
- `Skills`：浏览内置 Skill、创建或维护 Workspace 级 Skill（按权限开放）。
- `MCP Connections`：管理 MCP Server 连接、连接状态、工具发现、工具启停和权限范围。不要在列表中暴露访问令牌。
- `Agents`：配置 Agent 可用的 Workflow、Knowledge Base、Skill 和 MCP 工具白名单。
- `Workflow Editor` 的 LLM 节点属性面板新增 `Skills` 与 `MCP Tools` 配置区域，可选择本节点允许使用的能力。

聊天页面的单次会话选择和 Agent / Workflow 的持久化配置需要分开存储：前者影响当前请求，后者是可复用配置并必须在每次执行时重新进行权限校验。
